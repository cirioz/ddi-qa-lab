# DDI QA Lab

A portfolio project simulating QA engineering work on real network-infrastructure software.

## What it tests
- NetBox IPAM REST API - prefix and IP address management workflows
- PowerDNS REST API — zone and DNS record management
- End-to-end integration between IPAM and DNS systems

## Technologies
- TypeScript / JavaScript
- Playwright
- NetBox
- PowerDNS
- Docker / Docker Compose
- GitHub Actions
- Locust / Python
